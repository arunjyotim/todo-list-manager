# Todo List Manager

This application lets users create, filter, and organize tasks through a drag and drop interface.

## Features

- Add and remove tasks
- Filter by status
- Drag and drop reordering
- Persistent local storage

## How it works

The application listens for form submissions to add tasks into an array stored in browser local storage. Users can drag task items to reorder them or click checkboxes to toggle completion states.

## Run

Open `index.html` in a browser. No install or build step.
